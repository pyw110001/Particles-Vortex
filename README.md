# Particles-Vortex / WebGL 粒子旋涡工程

一个基于 **WebGL2 + GLSL** 的交互粒子系统工程。项目使用 **GPU Ping-Pong 状态纹理** 在片元着色器中完成粒子位置与速度更新，并通过点精灵与加法混合渲染出具有拖尾、旋涡、流场和点击爆发效果的实时视觉。

## 核心升级

- **纯 WebGL2 渲染管线**：移除了 p5.js 依赖，改为直接管理着色器、帧缓冲与纹理状态。
- **GPU 状态模拟**：粒子位置与速度以浮点纹理形式存储，通过双缓冲循环更新。
- **交互式流场**：粒子受噪声流场、中心回拉、鼠标吸附与切向旋涡共同驱动。
- **拖尾合成**：离屏场景纹理持续衰减，随后将粒子叠加到同一纹理中再输出到屏幕。
- **工程化控制台**：提供分辨率、拖尾、点尺寸、色散、吸力、旋涡、阻尼、爆发等参数控制。

## 文件结构

- `Luminous_Resonance.html`：应用入口、布局和控制面板。
- `styles.css`：控制台与渲染舞台的样式。
- `app.js`：WebGL 初始化、GPU 仿真、交互、动画循环与 UI 绑定。

## 运行方式

直接在现代浏览器中打开 `Luminous_Resonance.html` 即可。

> 建议使用支持 **WebGL2** 和 `EXT_color_buffer_float` 的 Chrome、Edge、Firefox 或 Safari 最新版本。

## 交互说明

- **移动鼠标**：粒子向光标聚集并产生旋涡。
- **按住鼠标左键**：持续向外施加爆发力。
- **随机种子**：重建初始粒子分布和噪声相位。
- **切换粒子分辨率**：重建 GPU 状态纹理，粒子数量变为 `resolution²`。

## 技术实现摘要

1. **初始化阶段**
   - 创建 WebGL2 上下文。
   - 检查浮点颜色附件扩展。
   - 编译模拟、粒子渲染、拖尾衰减与最终 Blit 着色器。
2. **状态模拟阶段**
   - 在离屏帧缓冲中读取上一帧位置/速度纹理。
   - 使用噪声流场、鼠标吸力、切向力与阻尼更新状态。
   - 将结果写入另一组浮点纹理，然后交换读写目标。
3. **渲染阶段**
   - 先对离屏场景纹理做透明衰减，保留拖尾。
   - 以 `gl.POINTS` 渲染全部粒子并使用加法混合增强发光效果。
   - 最后将离屏纹理整体绘制到屏幕。
